# DATASCAPE 2.0 Launch Website (ds-launch)

Official launch website for **DATASCAPE 2.0** — National Level Hackathon organized by Panimalar Engineering College. *Where Data Meets Imagination.*

## 🚀 Tech Stack

- **React 19**
- **TypeScript**
- **Vite**
- **Tailwind CSS v4**
- **Three.js** (Interactive 3D background)
- **Framer Motion** (Fluid animations)
- **Lucide React** (Icons)
- **Canvas Confetti**

## 🛠️ Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or pnpm or yarn

### Installation

```bash
npm install
```

### Running Locally

```bash
npm run dev
```

### Building for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
